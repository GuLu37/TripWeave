# 工具表

本 Skill 用于帮助规划 Agent 根据用户需求选择并使用工具库中的对应工具；仅在任务需要时加载相关工具说明。
工具库绝对路径：`E:\code\TripWeave\backend\app\tools`

## map_route_tool
高德地图工具：将目的地与 POI 转换为坐标，并提供地点检索和路线规划能力。

## accommodation_tool
住宿查询工具：按城市或坐标查询酒店与其他住宿地点候选。

## attraction_tool
景点查询工具：按城市或坐标查询风景名胜地点候选。

## food_tool
餐饮查询工具：按城市或坐标查询餐厅与菜系地点候选。

## weather_tool
天气查询工具：按坐标查询天气预报、实时天气和当前生效预警。

## transport_tool
本地交通工具：基于两个坐标比较公交、步行、驾车和骑行路线。
